# Scaleri Program Info

This is Scaleri's program info which contains information about:

- Application name and logo (and branding in general)
- Various URLs and API endpoints
- Desktop file

All logos and icons in this folder are generated from the pixel art in `genicons.py`.
To change them, edit that script and run `python3 program_info/genicons.py` (needs `rsvg-convert`).
